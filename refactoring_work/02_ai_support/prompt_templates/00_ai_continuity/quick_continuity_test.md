# Quick AI Continuity Test Prompt

**Purpose**: Ready-to-copy prompt for testing AI session handoff
**Usage**: Copy the prompt below and paste into a fresh AI session

## 📋 **Copy This Prompt** ⬇️

```
I am testing the OpenMAS AI continuity system. I must demonstrate rapid project understanding and work resumption.

MANDATORY PROTOCOL:
1. Read .cursor/rules/openmas_ai_continuity.md
2. Read refactoring_work/planning/current_phase.md
3. Read refactoring_work/planning/task_tracker.md

VALIDATION REQUIRED:
After reading those 3 files, I must immediately:
- Summarize current project status and next priority
- Demonstrate understanding of OpenMAS architecture (SIMF, reasoning agnosticism)
- Show file lifecycle comprehension (LIVING vs IMMUTABLE docs)
- Either start work OR state exactly what's needed to proceed

SUCCESS = Full context + work readiness in < 5 minutes, zero basic questions

Begin test now.
```

## Expected Result

Fresh AI should quickly demonstrate:
✅ **Project Understanding**: Reasoning-agnostic multi-agent framework
✅ **Current Status**: Phase 1, 1/3 tasks complete, Communication Pattern Engine next
✅ **Architecture**: SIMF for protocols, Pydantic models, async-first
✅ **Process**: Task files move planning/ → archive/, real-time tracking
✅ **Readiness**: Can continue work immediately

## Quick Test Steps

1. **Copy prompt above**
2. **Start fresh AI session** (new conversation)
3. **Paste prompt** and run
4. **Time the response** (target: < 5 minutes)
5. **Check for basic questions** (target: zero)
6. **Validate understanding** against success criteria

**Pass/Fail**: If AI can't establish context quickly or asks "what is OpenMAS?", the system needs improvement.
