# Testing Tools

## Overview

This directory contains documentation for testing tools and utilities used in OpenMAS testing. These tools support the testing of OpenMAS components across multiple protocols and reasoning engines, maintaining OpenMAS's reasoning-agnostic architecture.

## Contents

- [Test Frameworks](./test_frameworks.md) - Testing frameworks used with OpenMAS
- [Mock Services](./mock_services.md) - Mock services for testing OpenMAS components

## Key Testing Tools

OpenMAS testing relies on several key tools and utilities:

1. **Protocol Testing Tools**: Protocol-specific testing tools for A2A, MCP, HTTP, MQTT, and gRPC
2. **Reasoning Engine Mocks**: Mock implementations of various reasoning engines
3. **Agent Simulators**: Tools for simulating agent behavior in tests
4. **Test Supervisors**: Tools for orchestrating multi-agent test scenarios
5. **Configuration Generators**: Tools for generating test configurations
