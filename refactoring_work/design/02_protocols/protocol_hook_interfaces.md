# Protocol Message Pre/Post-Processing Hook Interfaces

## 1. Overview

To maintain a clean separation of concerns, the OpenMAS protocol layer supports hooks that allow for protocol-specific transformations of messages before they are converted to the Standard Internal Message Format (SIMF) and after they have been converted from SIMF. These hooks are essential for adapting to various protocol-specific message structures, headers, or metadata without cluttering the core `IProtocolAdapter` logic.

This document defines two key interfaces:

-   `IMessagePreprocessor`: For processing incoming raw protocol messages *before* they are passed to the `IProtocolAdapter.to_internal_format()` method.
-   `IMessagePostprocessor`: For processing outgoing raw protocol messages *after* they have been generated by the `IProtocolAdapter.from_internal_format()` method.

## 2. Interface Definitions

These interfaces are designed to be simple, asynchronous, and chainable, allowing multiple hooks to be applied in a defined order.

```python
from abc import ABC, abstractmethod
from typing import Any

class IMessagePreprocessor(ABC):
    """
    An interface for a hook that processes a raw message from a specific
    protocol before it is converted to the Standard Internal Message Format (SIMF).
    """

    @abstractmethod
    async def process(self, raw_message: Any) -> Any:
        """
        Processes the incoming raw message.

        This could involve adding/removing headers, transforming the payload,
        or performing any other necessary modifications.

        Args:
            raw_message: The raw message received from the transport layer.

        Returns:
            The processed message, which will then be passed to the protocol adapter.
        """
        ...

class IMessagePostprocessor(ABC):
    """
    An interface for a hook that processes a raw message for a specific
    protocol after it has been converted from the Standard Internal Message
    Format (SIMF).
    """

    @abstractmethod
    async def process(self, raw_message: Any) -> Any:
        """
        Processes the outgoing raw message.

        This is the final step before the message is sent over the transport layer.

        Args:
            raw_message: The raw message generated by the protocol adapter.

        Returns:
            The final processed message to be sent.
        """
        ...

```

## 3. Integration with Protocol Layer

Implementations of these hooks are registered with the `IProtocolAdapter` or a `ProtocolInterfaceFactory`. The protocol adapter is then responsible for invoking the registered hooks at the appropriate stage of the message lifecycle.

### Example Invocation Flow:

**Incoming Message:**
1.  Raw message received by `IMessageTransport`.
2.  Message passed to `IProtocolAdapter`.
3.  `IProtocolAdapter` invokes all registered `IMessagePreprocessor` hooks in order.
4.  The final processed message is passed to `IProtocolAdapter.to_internal_format()`.

**Outgoing Message:**
1.  SIMF message passed to `IProtocolAdapter.from_internal_format()`.
2.  Raw protocol message is generated.
3.  `IProtocolAdapter` invokes all registered `IMessagePostprocessor` hooks in order.
4.  The final processed message is passed to `IMessageTransport` to be sent.
