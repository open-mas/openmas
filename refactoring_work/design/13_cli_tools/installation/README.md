# OpenMAS CLI Installation

## Overview

This directory provides documentation on installing and setting up the OpenMAS Command Line Interface (CLI) tools. The OpenMAS CLI provides a comprehensive set of tools for managing your multi-agent system projects, supporting OpenMAS's reasoning-agnostic architecture and multi-protocol capabilities.

## Contents

- [Installation Guide](./installation_guide.md): Detailed instructions for installing the OpenMAS CLI tools
- Prerequisites and system requirements
- Installation options and methods
- Verifying your installation

## Quick Start

To install the OpenMAS CLI tools:

```bash
pip install openmas
```

For detailed instructions and options, refer to the [Installation Guide](./installation_guide.md).
