# DEPRECATED: ICapabilityManager Interface

This file is deprecated and should not be used. The monolithic `ICapabilityManager` interface has been replaced by a more modular design that separates concerns.

## Canonical Interfaces

Please use the following interfaces for capability management:

-   **`ICapabilityRegistry`**: For registering and discovering capabilities.
-   **`ICapabilityInvoker`**: For executing capabilities.

These interfaces are defined in the following document:

-   **[Agent Capability Management Interfaces](./capability_management_interfaces.md)**
