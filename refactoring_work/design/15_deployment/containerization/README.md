# Containerization

## Overview

This directory contains documentation for deploying OpenMAS using containerization technologies such as Docker and Docker Compose. Containerization provides consistent, isolated, and reproducible environments for running OpenMAS agents and systems.

## Deployment Options

- **Docker Containers**: Running individual agents as Docker containers
- **Docker Compose**: Orchestrating multi-agent systems with Docker Compose
- **Testing Containers**: Specialized containers for testing OpenMAS components
- **Development Containers**: Container environments for development
